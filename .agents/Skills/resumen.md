# Resumen de Skills Disponibles

## Planner-agent
- Planificación técnica, auditoría de arquitectura, generación de planes de acción
- No escribe código — solo estructura y documenta

## Executor-agent
- Ejecución de planes: escribe código, modifica archivos, implementa cambios
- Trabaja con Android (Kotlin/XML), React (JSX/CSS), backend (Node.js)

## Orchestador-agent
- Coordina múltiples agentes, descompone tareas complejas, gestiona flujos de trabajo

## Auditor-agent
- Revisa código, detecta bugs, verifica consistencia, analiza riesgos
